Babu Birthday V2
1. Upload index.html and the whole assets folder to a PUBLIC GitHub repository.
2. Put your five photos in assets and rename them photo1.jpg ... photo5.jpg.
3. In index.html replace photo1.svg etc. with photo1.jpg etc.
4. GitHub: Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.
5. Send the GitHub Pages URL, not the repository editing URL.
6. Music starts after the first tap because mobile browsers restrict autoplay.
